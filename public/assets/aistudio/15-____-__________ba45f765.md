# 背景优化 · 给外部 AI 的可复制粘贴包

> 这份文档把「背景是空白 / 人物站床上」两个问题的修复拆成**四块独立代码**。
> 每块都标了文件名、位置、替换前、替换后。对方只要照抄就行，不需要解压任何文件。

---

## 一、改了哪两个文件

```
src/types/studio.ts      ← 在 NegativeGroupId 联合类型里加 'anti-blank-bg'
src/data/presets.ts      ← 改背景预设 + 加新负向组 + 改默认背景 + 压「站床上」
```

### 改动 3.2：默认背景

**位置**：`DEFAULT_STUDIO_CONFIG.shared.background`

**改前**：

```ts
    background: {
      text: 'simple background, pale cool sky blue background, clean studio backdrop, subtle floor shadow',
      weight: 1.0,
    },
```

**改后**：

```ts
    background: {
      text: 'detailed background, indoor, school classroom, afternoon sunlight through windows, wooden desks and chairs, chalkboard, curtains, tiled floor, depth of field',
      weight: 1.45,
    },
```

要点：
- `detailed background` 必须放最前面（句子越靠前权重越高）
- 必须给地板（`tiled floor`），不然人物会站桌上
- 权重从 1.0 提到 1.45

## 四、为什么要这么改（一句话解释，给对接 AI 看）

| 症状 | 根因 | 修法 |
|---|---|---|
| 背景全是空白 / 纯色 | 正向里只有 `on bed` 这类名词，模型理解为「人物在床上」但不画场景；同时没有负向压白底 | 加 anti-blank-bg 负向组 + 背景词以 `detailed background` 开头 + 加权到 1.45 |
| 人物站在床上 | 背景写了 `white bed` 当主家具，动作又写了 `full body / standing`，模型给全身找落脚点就找床 | 床写成 `in background` 退到配角 + 加 `wooden floor / underfoot` 给脚落地 + 负向压 standing on bed |
| TypeScript 报错 | `NegativeGroupId` 是联合类型，新加的 id 不在里面 | 在 `studio.ts` 的联合类型里补上 |

## 六、如果还不够明显

把背景权重再往上拉：
- `1.45` → `1.6` → `1.8`
- 或者把 `detailed background` 在背景串里**重复写两遍**

不要往负向里加 `detailed background`，那会把整个场景压没。
